# Religion Trends in Leicester (2011–2021)

**Author:** Patrycja Oliwia Pyzikiewicz  
**Context:** Early university data analysis project based on UK Census data.

## Overview
This project explores demographic and religious changes in Leicester between 2011 and 2021 using UK Census data. The analysis compares trends among major and minor religious groups and examines long-term social and demographic changes within the city.

## Skills Used
- Data analysis
- Data visualization
- Demographic analysis
- Comparative analysis
- Research writing

## Key Topics
- Census analysis
- Demographic change
- Religion trends
- Urban diversity
- Population statistics

## Main Findings
- Christianity declined significantly between 2011 and 2021.
- Hindu and Muslim populations increased during the analysed period.
- Minor religions showed mixed trends, with growth in Jain and Spiritual groups.
- The share of residents with no religion remained relatively stable.
